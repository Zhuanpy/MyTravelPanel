# 国旗上传功能使用说明

## 🎯 功能概述
为国家管理页面添加了国旗上传功能，支持在添加和编辑国家时上传国旗图片。

## 📋 功能特性

### ✅ 支持的文件格式
- PNG
- JPG/JPEG  
- GIF
- SVG

### 📏 推荐图片规格
- **最佳尺寸**: 64x64px
- **宽高比**: 建议接近 4:3 或 3:2
- **文件大小**: 建议不超过 100KB

### 🔧 功能特点
1. **自动重命名**: 文件上传后自动按国家代码重命名（如：cn.png、us.jpg）
2. **文件预览**: 上传前可预览图片效果
3. **安全验证**: 只允许指定格式的图片文件
4. **旧文件清理**: 编辑时自动删除旧的国旗文件
5. **表格显示**: 在管理列表中直接显示国旗缩略图

## 🚀 使用方法

### 添加新国家时上传国旗
1. 点击"添加国家"按钮
2. 填写国家基本信息（中文名、英文名、国家代码）
3. 在"国旗图片"字段选择图片文件
4. 系统会自动显示预览图
5. 点击"添加国家"完成上传

### 编辑现有国家时上传国旗
1. 点击国家列表中的"编辑"按钮
2. 查看当前国旗（如有）
3. 选择新的国旗图片文件
4. 系统会显示新国旗预览
5. 点击"保存修改"完成更新

## 📁 文件存储
- **存储路径**: `App_new/static/images/flags/`
- **命名规则**: `{国家代码小写}.{扩展名}`
- **示例**: 
  - 中国: `cn.png`
  - 美国: `us.jpg`
  - 日本: `jp.gif`

## 🗄️ 数据库变更
- 在 `visa_countries` 表中新增 `flag_file` 字段
- 存储国旗文件名
- 执行迁移脚本: `migrations/add_country_flag_file.sql`

## 🔗 前端显示
- 国家管理列表显示国旗缩略图（32x24px）
- 签证服务页面显示国旗图标（响应式尺寸）
- 支持图片加载失败时自动隐藏

## ⚠️ 注意事项
1. 请确保上传的图片质量清晰
2. 建议使用标准化的国家代码（ISO 3166-1 alpha-2）
3. 图片文件不要过大，以免影响页面加载速度
4. 编辑国家时会自动替换旧国旗，请确认新图片正确

## 🛠️ 技术实现
- **后端**: Flask + SQLAlchemy + Werkzeug
- **前端**: HTML5 File API + FileReader
- **文件处理**: 自动创建目录、安全文件名、类型验证
- **响应式设计**: 支持各种屏幕尺寸的国旗显示
