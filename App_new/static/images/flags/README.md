# 国旗图片说明

## 文件命名规则
- 文件名必须与国家代码的小写形式一致
- 例如：中国 = `cn.png`，美国 = `us.png`，日本 = `jp.png`

## 推荐尺寸
- **主要尺寸**: 64x64px
- **文件格式**: PNG (支持透明背景)
- **文件大小**: 建议不超过 10KB

## 图片获取建议
1. 使用免费的国旗图标库（如 Flaticon, IconFinder）
2. 确保图片质量清晰，适合小尺寸显示
3. 保持一致的视觉风格
4. 支持透明背景，便于在不同背景下显示

## 注意事项
- 如果某个国家的国旗图片不存在，系统会自动隐藏该国旗显示
- 建议使用标准化的国家代码（ISO 3166-1 alpha-2）
