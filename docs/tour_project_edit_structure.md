## 🎯 优化要点

### 1️⃣ 颜色体系

| 区域 | 颜色 | 含义 |
|------|------|------|
| 页面头部 | 🟢 绿色渐变 | 主标题 |
| 项目基本信息 | 🟢 绿色 | 项目级信息 |
| 团队管理外层 | 🔵 蓝色 | 团队容器 |
| 团队卡片 | 蓝色边框 + 淡蓝背景 | 单个团队 |
| 行程区域 | 虚线分隔 | 团队的子内容 |

---

### 2️⃣ 层级关系

```
项目（Project）
  ├─ 项目基本信息（Display Only，可编辑）
  │
  └─ 团队管理（Container）
      ├─ 团队1（Card）
      │   ├─ 团队信息（Grid）
      │   └─ 行程安排（Table）
      │
      └─ 团队2（Card）
          └─ ...
```

---

### 3️⃣ 视觉层次

**卡片嵌套深度**：
```
Level 1: 项目基本信息卡片
Level 1: 团队管理卡片
  Level 2: 团队1卡片
    Level 3: 行程表格（在团队卡片内）
  Level 2: 团队2卡片
    Level 3: 行程表格
```

**避免过深嵌套**：
- ✅ 最多3层卡片
- ✅ 使用虚线分隔代替新卡片
- ✅ 使用背景色和边框区分层级

---

### 4️⃣ 操作按钮位置

| 按钮 | 位置 | 作用域 |
|------|------|--------|
| **编辑项目** | 项目基本信息 - 右上角 | 项目级 |
| **创建团队** | 团队管理 - 右上角 | 团队容器级 |
| **编辑/删除团队** | 团队卡片 - 右上角 | 单个团队 |
| **添加/自动生成行程** | 行程小标题 - 右侧 | 单个团队的行程 |
| **编辑/删除行程** | 行程表格 - 行内 | 单条行程 |
| **返回/查看详情** | 页面底部 | 页面级 |

## ✅ 总结

### 核心改进

1. **结构清晰**：项目 → 团队 → 行程，层级分明
2. **视觉区分**：颜色、边框、虚线分隔
3. **操作集中**：按钮位置符合用户操作习惯
4. **无重复**：删除冗余的操作按钮

### 用户体验提升

| 改进项 | 优化前 | 优化后 |
|--------|--------|--------|
| 找到"创建团队" | ❌ 需滚动或在空状态才显示 | ✅ 固定在团队管理卡片头部 |
| 添加行程 | ❌ 在表格底部，不醒目 | ✅ 在行程小标题右侧，显眼 |
| 页面导航 | ❌ 没有返回按钮 | ✅ 底部有明确操作按钮 |
| 层级理解 | ❌ 扁平结构，难以区分 | ✅ 卡片嵌套，层次分明 |
