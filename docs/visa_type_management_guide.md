# 签证类型管理功能使用指南

## 功能概述

签证类型管理是一个完整的签证类型配置和管理系统，包含以下核心功能：

1. **新建签证类型** - 创建新的签证类型，配置基本信息
2. **文档配置** - 为每个签证类型配置所需的文档清单
3. **模板文件管理** - 上传和管理签证申请所需的模板文件
4. **签证类型列表** - 查看和管理所有已创建的签证类型

## 功能架构

### 1. 新建签证类型

#### 功能特点
- 配置基本信息（名称、国家、费用、处理时间）
- 选择适用的新加坡身份（PR、EP、SP等）
- 自动创建文件夹结构
- 支持多种身份同时配置

#### 使用步骤
1. 点击"新建签证类型"卡片
2. 填写签证类型基本信息
3. 选择适用的新加坡身份
4. 系统自动创建对应的文件夹结构

#### 文件夹结构
```
资源/签证/[签证类型名称]/
├── 共用资料/
├── PR/
├── EP/
├── SP/
└── 模板文件/
    ├── 共用模板/
    ├── PR/
    ├── EP/
    └── SP/
```

### 2. 文档配置

#### 功能特点
- 为每个身份配置所需的文档清单
- 设置文档准备方（申请人/旅行社）
- 添加注意事项和特殊要求
- 支持共用资料配置

#### 使用步骤
1. 点击"文档配置"卡片
2. 选择要配置的签证类型
3. 选择身份（或共用资料）
4. 配置所需的文档清单
5. 设置文档准备方和注意事项

#### 配置内容
- **文档名称** - 所需文档的具体名称
- **准备方** - FOR_APPLICATION（申请人准备）或 FOR_AGENT（旅行社准备）
- **注意事项** - 特殊要求或说明

### 3. 模板文件管理

#### 功能特点
- 上传多种格式的模板文件（PDF、DOC、DOCX、XLS、XLSX、TXT、JPG、PNG）
- 按身份分类管理模板文件
- 支持模板类型分类（公司信、邀请信、申请表等）
- 文件下载和删除功能

#### 支持的模板类型
- 公司信
- 邀请信
- 申请表
- 行程安排
- 酒店预订
- 机票预订
- 其他

#### 使用步骤
1. 点击"模板文件管理"卡片
2. 选择签证类型
3. 选择适用身份（或共用模板）
4. 点击"上传模板"按钮
5. 填写模板信息并选择文件
6. 上传完成后可在列表中查看和管理

#### 文件管理功能
- **上传** - 支持拖拽上传和点击选择
- **下载** - 点击下载按钮直接下载文件
- **删除** - 删除不需要的模板文件
- **预览** - 查看文件信息和描述

### 4. 签证类型列表

#### 功能特点
- 查看所有已创建的签证类型
- 显示基本信息（国家、费用、处理时间、适用身份）
- 快速跳转到文档配置和模板管理
- 支持编辑和删除操作

#### 操作功能
- **编辑费用** - 修改签证申请费用
- **编辑时间** - 修改处理时间
- **编辑身份** - 修改适用的新加坡身份
- **编辑文档** - 跳转到文档配置页面
- **模板管理** - 跳转到模板文件管理页面
- **删除** - 删除整个签证类型（谨慎操作）

## 数据库结构

### 核心表结构

#### visa_types（签证类型表）
- `id` - 主键
- `visa_type` - 签证类型名称
- `processing_time` - 处理时间
- `fee` - 申请费用
- `country_id` - 所属国家ID

#### visa_template_files（模板文件表）
- `id` - 主键
- `visa_type_id` - 签证类型ID
- `singapore_identity_id` - 新加坡身份ID（可为空，表示共用模板）
- `template_name` - 模板名称
- `template_type` - 模板类型
- `file_path` - 文件路径
- `file_size` - 文件大小
- `file_type` - 文件类型
- `description` - 描述信息
- `is_active` - 是否激活

#### visa_documents_request（文档配置表）
- `id` - 主键
- `visa_type_id` - 签证类型ID
- `singapore_identity_id` - 新加坡身份ID（可为空，表示共用资料）
- `additional_info` - 注意事项

## 使用建议

### 1. 创建新签证类型的建议流程
1. 先创建签证类型基本信息
2. 配置文档清单和注意事项
3. 上传相关的模板文件
4. 测试整个流程

### 2. 模板文件管理建议
- 使用清晰的命名规范
- 按类型分类上传
- 添加详细的描述信息
- 定期清理不需要的文件

### 3. 文档配置建议
- 确保文档清单的完整性
- 明确标注准备方
- 添加必要的注意事项
- 定期更新配置信息

## 注意事项

### 1. 文件安全
- 只上传必要的模板文件
- 定期检查文件安全性
- 删除不需要的文件

### 2. 数据备份
- 定期备份数据库
- 备份重要的模板文件
- 建立数据恢复机制

### 3. 权限管理
- 限制上传文件的大小
- 控制文件类型
- 设置访问权限

## 故障排除

### 常见问题

1. **文件上传失败**
   - 检查文件大小是否超限
   - 确认文件类型是否支持
   - 检查磁盘空间是否充足

2. **模板文件无法下载**
   - 检查文件路径是否正确
   - 确认文件是否存在
   - 检查文件权限

3. **文档配置不生效**
   - 检查数据库连接
   - 确认配置是否正确保存
   - 清除浏览器缓存
