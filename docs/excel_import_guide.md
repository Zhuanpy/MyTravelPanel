# Excel数据导入功能使用指南

## 功能概述

客户公司管理页面新增了Excel数据导入功能，支持批量导入公司信息，提高数据录入效率。

## 功能特点

- **支持格式**: .xlsx 和 .xls 格式
- **数据预览**: 导入前可预览数据，确保数据正确性
- **错误处理**: 详细的错误提示和验证
- **模板下载**: 提供标准Excel模板
- **批量导入**: 支持一次性导入多条记录

## 使用步骤

### 1. 下载模板

1. 进入客户公司管理页面
2. 点击"Excel导入"按钮
3. 在弹窗中点击"下载模板"按钮
4. 下载Excel模板文件

### 2. 填写数据

按照模板格式填写公司信息：

| 字段 | 说明 | 必填 | 示例 |
|------|------|------|------|
| 公司名称 * | 公司全称 | 是 | 示例公司A |
| 公司代码 | 公司内部代码 | 否 | CODE001 |
| 联系人 | 主要联系人姓名 | 否 | 张三 |
| 联系电话 | 联系人电话 | 否 | 13800138000 |
| 邮箱 | 联系邮箱 | 否 | zhangsan@example.com |
| 行业 | 公司所属行业 | 否 | 科技 |
| 规模 | 公司规模 | 否 | 中型公司 |
| 状态 | 公司状态 | 否 | active |

### 3. 行业选项

支持以下行业类型：
- 科技
- 金融
- 制造业
- 医疗健康
- 教育
- 零售
- 旅游
- 房地产
- 咨询
- 其他

### 4. 规模选项

支持以下规模类型：
- 初创公司
- 小型公司
- 中型公司
- 大型公司
- 企业级

### 5. 状态选项

支持以下状态：
- active (活跃)
- inactive (非活跃)
- suspended (暂停)

### 6. 导入数据

1. 点击"选择文件"按钮
2. 选择填写好的Excel文件
3. 系统自动读取并预览数据
4. 检查数据无误后点击"确认导入"
5. 查看导入结果

## 数据验证规则

### 必填字段验证
- 公司名称不能为空
- 公司名称不能重复（系统中已存在的公司名称）

### 数据格式验证
- 行业、规模、状态会自动映射到标准值
- 支持中英文混合输入
- 自动过滤空行

### 错误处理
- 显示具体的错误行号和错误原因
- 成功导入的记录会正常保存
- 失败的记录会显示详细错误信息

## 注意事项

1. **文件格式**: 仅支持.xlsx和.xls格式
2. **数据量**: 建议单次导入不超过1000条记录
3. **编码**: 建议使用UTF-8编码保存Excel文件
4. **重复检查**: 系统会自动检查公司名称重复
5. **数据备份**: 建议在导入前备份现有数据

## 常见问题

### Q: 导入失败怎么办？
A: 检查以下几点：
- 确保公司名称不为空
- 检查公司名称是否重复
- 验证Excel文件格式是否正确
- 查看错误提示信息

### Q: 如何修改已导入的数据？
A: 可以通过以下方式：
- 在列表中点击"编辑"按钮
- 使用批量编辑功能（如果支持）
- 删除后重新导入

### Q: 支持哪些Excel版本？
A: 支持Excel 2007及以上版本（.xlsx格式）和Excel 97-2003版本（.xls格式）

## 技术实现

### 前端技术
- 使用XLSX.js库解析Excel文件
- Bootstrap模态框实现用户界面
- JavaScript处理文件上传和数据预览

### 后端技术
- Python pandas处理Excel数据
- Flask路由处理文件上传
- SQLAlchemy进行数据库操作

### 依赖库
- pandas: 数据处理
- openpyxl: Excel文件读写
- XLSX.js: 前端Excel解析
