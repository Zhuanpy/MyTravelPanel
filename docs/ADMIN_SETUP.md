# MyTravelPanel 管理员设置指南

## 🚀 第一次部署系统

### 步骤1：创建第一个超级管理员

```bash
python create_admin.py
```

按照提示输入管理员信息：
- 邮箱地址
- 用户名
- 姓名信息
- 联系电话（可选）
- 密码

### 步骤2：登录管理员后台

1. 访问：`http://127.0.0.1:5000/portal`
2. 点击红色的"管理员后台"卡片
3. 使用刚创建的邮箱和密码登录

### 步骤3：创建邀请码

1. 在管理员仪表板中，点击"邀请码管理"
2. 点击"创建邀请码"
3. 选择角色类型（员工/管理员）
4. 设置生成数量和有效期
5. 点击"创建邀请码"

## 📋 邀请码使用流程

### 员工注册流程

1. **管理员操作**：
   - 登录管理员后台
   - 邀请码管理 → 创建邀请码
   - 选择"员工"角色
   - 将生成的邀请码发送给员工

2. **员工操作**：
   - 访问：`http://127.0.0.1:5000/portal`
   - 点击蓝色的"员工工作台"卡片
   - 点击"注册员工账户（需要邀请码）"
   - 输入管理员提供的邀请码
   - 填写个人信息完成注册

### 管理员注册流程

1. **超级管理员操作**：
   - 登录管理员后台
   - 邀请码管理 → 创建邀请码
   - 选择"管理员"角色
   - 将生成的邀请码发送给新管理员

2. **新管理员操作**：
   - 访问：`http://127.0.0.1:5000/portal`
   - 点击红色的"管理员后台"卡片
   - 点击"注册管理员账户（需要超管邀请码）"
   - 输入超级管理员提供的邀请码
   - 填写个人信息完成注册

## 🔧 管理功能

### 邀请码管理

- **查看邀请码列表**：显示所有邀请码的状态、使用情况
- **创建邀请码**：批量生成指定角色的邀请码
- **撤销邀请码**：撤销未使用的邀请码
- **设置有效期**：为邀请码设置过期时间

### 系统检查

```bash
python create_admin.py
# 选择选项 2：检查系统状态
```

查看：
- 系统角色统计
- 各角色用户数量
- 管理员账户列表

## ⚠️ 安全注意事项

1. **妥善保管邀请码**：每个邀请码只能使用一次
2. **设置合理有效期**：避免邀请码长期有效带来安全风险
3. **定期清理**：撤销不需要的邀请码
4. **权限控制**：谨慎分配管理员权限

## 🎯 角色权限说明

| 角色 | 权限范围 | 主要功能 |
|------|----------|----------|
| **会员** | 基础权限 | 查看服务、提交申请、管理个人信息 |
| **员工** | 业务权限 | 处理客户服务、管理项目、上传文件 |
| **管理员** | 完整权限 | 用户管理、权限控制、系统配置、邀请码管理 |

## 🆘 常见问题

**Q：忘记了管理员密码怎么办？**
A：重新运行 `python create_admin.py` 创建新的管理员账户

**Q：邀请码用完了怎么办？**
A：管理员登录后台，在邀请码管理中创建新的邀请码

**Q：如何撤销某个用户的权限？**
A：在管理员后台的用户管理中可以修改用户角色或禁用账户

**Q：员工能创建邀请码吗？**
A：不能，只有管理员才能创建和管理邀请码
