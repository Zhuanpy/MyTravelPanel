# 配套价格预算功能使用指南

## 功能概述

配套价格预算功能是一个完整的预算管理系统，用于创建、管理和跟踪旅游配套的价格预算。该功能支持：

- 创建和管理预算单
- 添加详细的预算项目
- 支持成人和儿童不同价格
- 税费计算
- 模板功能
- 导入导出功能

## 主要功能

### 1. 预算单管理

#### 创建预算单
- 访问路径：配套 → 价格预算 → 新建预算单
- 填写基本信息：套餐名称、成人数量、儿童数量、币种等
- 设置状态（草稿/激活/归档）
- 可选择设为模板

#### 查看预算单列表
- 支持搜索和筛选
- 按状态、类型筛选
- 分页显示
- 快速操作（查看、编辑、删除）

#### 编辑预算单
- 修改基本信息
- 实时预览功能
- 表单验证

### 2. 预算项目管理

#### 添加项目
- 在预算单详情页面添加明细项目
- 支持分类管理（住宿、交通、门票等）
- 设置成人和儿童价格
- 配置税费信息
- 设置可选/必需项目

#### 项目属性
- **类别**：项目分类（如住宿、交通、门票）
- **项目类型**：具体类型（如酒店、机票、景点）
- **项目名称**：详细描述
- **价格设置**：
  - 成人单价
  - 儿童单价
  - 总价覆盖（直接设置总价）
- **适用人数**：
  - 计成人费用
  - 计儿童费用
  - 人数覆盖（自定义人数）
- **税费**：
  - 税率（百分比）
  - 税费金额（固定金额）
- **其他**：
  - 排序
  - 可选项目标记
  - 备注

### 3. 模板功能

#### 创建模板
- 在创建或编辑预算单时勾选"设为模板"
- 模板可以重复使用

#### 使用模板
- 在模板列表中选择模板
- 点击"使用模板"创建新的预算单
- 自动复制所有项目和设置

### 4. 导入导出

#### 导出功能
- 支持导出为JSON格式
- 包含完整的预算单和项目数据
- 可用于备份或数据迁移

#### 导入功能
- 支持JSON格式文件导入
- 可选择覆盖现有数据
- 支持导入为模板

## 数据模型

### BudgetHeader（预算单头）
```python
- id: 主键
- package_name: 套餐名称
- adult_count: 成人数量
- child_count: 儿童数量
- currency: 币种
- status: 状态（draft/active/archived）
- is_template: 是否为模板
- created_by: 创建人
- created_at: 创建时间
- updated_at: 更新时间
- remarks: 备注
```

### BudgetItem（预算项目）
```python
- id: 主键
- header_id: 关联预算单ID
- category: 类别
- item_type: 项目类型
- item_name: 项目名称
- adult_price: 成人单价
- child_price: 儿童单价
- total_override: 总价覆盖
- count_adult_apply: 计成人费用
- count_child_apply: 计儿童费用
- adult_count_override: 成人人数覆盖
- child_count_override: 儿童人数覆盖
- sort_order: 排序
- tax_rate: 税率
- tax_amount: 税费金额
- is_optional: 可选项目
- remarks: 备注
```

## 计算逻辑

### 小计计算
1. 如果设置了总价覆盖，直接使用覆盖值
2. 否则按以下公式计算：
   ```
   小计 = (成人单价 × 成人人数) + (儿童单价 × 儿童人数)
   ```
3. 如果设置了税率，加上税费：
   ```
   税费 = 小计 × 税率
   ```
4. 如果设置了固定税费金额，直接加上

### 总价计算
```
总价 = 所有项目小计之和
```

## 使用流程

### 创建新预算单
1. 点击"新建预算单"
2. 填写基本信息
3. 保存预算单
4. 在详情页面添加项目
5. 设置项目价格和属性
6. 查看总价和分类统计

### 使用模板
1. 访问模板列表
2. 选择合适模板
3. 点击"使用模板"
4. 修改相关信息
5. 保存为新预算单

### 管理现有预算单
1. 在列表页面查看所有预算单
2. 使用搜索和筛选功能
3. 点击"查看"进入详情页面
4. 编辑或添加项目
5. 导出或删除预算单

## 注意事项

1. **数据验证**：系统会验证必填字段和价格设置
2. **权限控制**：确保用户有相应权限
3. **备份建议**：定期导出重要预算单
4. **模板使用**：建议创建常用模板提高效率
5. **税费计算**：注意税率和固定税费的区别
