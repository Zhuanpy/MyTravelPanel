## 🐛 常见错误处理

### 错误 1: "Duplicate column name"
**原因**: 列已存在
**解决**: 跳过该列的添加，继续执行

### 错误 2: "Cannot add foreign key"
**原因**: suppliers 表不存在或 supplier_id 列不存在
**解决**: 
```sql
-- 检查 suppliers 表
SHOW TABLES LIKE 'suppliers';
DESCRIBE suppliers;
```

### 错误 3: "Duplicate key name"
**原因**: 索引已存在
**解决**: 忽略或先删除再创建
