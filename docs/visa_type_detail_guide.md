# 签证类型详细功能使用指南

## 功能概述

签证类型详细功能提供了一个完整的签证类型信息展示页面，用户可以查看签证类型的所有相关信息，包括基本信息、文档配置、模板文件等。

## 功能特点

### 🎯 **核心功能**
- **完整信息展示** - 显示签证类型的所有基本信息
- **文档配置查看** - 按身份分类查看文档配置
- **模板文件管理** - 查看和管理相关的模板文件
- **统计信息** - 显示文档、模板、项目等统计信息
- **快速操作** - 提供快速跳转到配置页面的链接

### 📊 **信息展示**

#### 1. 统计信息卡片
- **配置文档数量** - 显示该签证类型配置的文档总数
- **模板文件数量** - 显示上传的模板文件数量
- **适用身份数量** - 显示适用的新加坡身份数量
- **相关项目数量** - 显示使用该签证类型的项目数量

#### 2. 基本信息卡片
- **签证类型名称** - 签证类型的完整名称
- **所属国家** - 签证类型对应的国家
- **申请费用** - 签证申请的费用信息
- **处理时间** - 签证处理的时间周期

#### 3. 适用身份卡片
- **身份标签** - 以标签形式显示所有适用的新加坡身份
- **身份分类** - 清晰展示PR、EP、SP等不同身份

#### 4. 相关链接卡片
- **外部链接** - 显示相关的申请链接或官方链接
- **链接管理** - 快速访问链接管理功能

### 📋 **文档配置区域**

#### 功能特点
- **身份标签切换** - 可以切换查看不同身份的文档配置
- **文档列表展示** - 显示每个身份需要准备的文档
- **准备方标识** - 明确标注文档由申请人还是旅行社准备
- **快速编辑** - 提供快速跳转到文档配置页面的链接

#### 使用方式
1. 点击身份标签（如"共用资料"、"PR"、"EP"等）
2. 查看该身份需要准备的所有文档
3. 查看文档的准备方和描述信息
4. 点击"编辑配置"进行修改

### 📁 **模板文件区域**

#### 功能特点
- **模板卡片展示** - 以卡片形式展示所有模板文件
- **文件信息显示** - 显示文件名、类型、大小、适用身份等
- **快速下载** - 提供模板文件的快速下载功能
- **分类管理** - 按模板类型进行分类显示

#### 模板类型
- **公司信** - 公司出具的证明信模板
- **邀请信** - 邀请函模板
- **申请表** - 签证申请表模板
- **行程安排** - 旅行行程安排模板
- **酒店预订** - 酒店预订确认模板
- **机票预订** - 机票预订确认模板
- **其他** - 其他类型的模板文件

## 页面导航

### 🔗 **快速操作按钮**

#### 页面头部操作
- **配置文档** - 跳转到文档配置页面
- **管理模板** - 跳转到模板文件管理页面
- **返回列表** - 返回到签证类型列表页面

#### 区域操作
- **编辑配置** - 在各个区域提供快速编辑链接
- **上传模板** - 快速跳转到模板上传功能

## 使用流程

### 1. 访问详细页面
1. 在签证类型列表页面点击"详细"按钮
2. 系统跳转到签证类型详细页面
3. 查看完整的签证类型信息

### 2. 查看文档配置
1. 在文档配置区域查看共用资料
2. 点击不同身份标签查看对应文档
3. 了解每个文档的准备方和描述

### 3. 管理模板文件
1. 在模板文件区域查看所有模板
2. 点击下载按钮下载需要的模板
3. 点击"上传模板"添加新的模板文件

### 4. 进行配置修改
1. 点击相应的"编辑配置"或"管理模板"按钮
2. 在配置页面进行修改
3. 保存后返回详细页面查看更新

## 技术实现

### 数据库查询
- **签证类型信息** - 从visa_types表获取基本信息
- **身份关联** - 通过多对多关系获取适用身份
- **文档配置** - 从visa_documents_request表获取文档配置
- **模板文件** - 从visa_template_files表获取模板信息
- **项目统计** - 从visa_projects表统计相关项目

### 页面渲染
- **响应式设计** - 支持桌面端和移动端
- **动态加载** - 根据身份标签动态切换文档显示
- **统计计算** - 实时计算各种统计数据
- **文件格式化** - 自动格式化文件大小显示

## 注意事项

### 1. 数据完整性
- 确保签证类型存在且有效
- 检查文档配置的完整性
- 验证模板文件的可用性

### 2. 权限控制
- 确保用户有查看权限
- 控制编辑和删除操作的权限
- 保护敏感文件的安全

### 3. 性能优化
- 合理控制页面加载时间
- 优化数据库查询效率
- 缓存常用的统计数据

## 故障排除

### 常见问题

1. **页面加载缓慢**
   - 检查数据库查询性能
   - 优化模板文件加载
   - 考虑使用缓存机制

2. **文档配置不显示**
   - 检查数据库连接
   - 验证文档配置数据
   - 确认身份关联正确

3. **模板文件无法下载**
   - 检查文件路径是否正确
   - 确认文件是否存在
   - 验证文件权限设置

### 技术支持

如遇到技术问题，请联系系统管理员或查看系统日志获取详细错误信息。
