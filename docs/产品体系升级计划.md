# 旅游产品体系升级计划

## 一、现有架构分析

### 已有模型
| 模块 | 模型 | 表名 | 说明 |
|-----|------|------|-----|
| 旅游产品 | Product | package_products | 旅游线路产品 |
| 旅游产品 | ProductItinerary | package_itinerary | 行程详情 |
| 旅游产品 | ProductPriceVariant | package_price_variant | 价格变体 |
| 签证 | VisaTypes | visa_types | 签证类型 |
| 签证 | VisaDocuments | visa_documents_request | 签证资料 |
| 机票 | ProjectFlightPassenger | project_flight_passengers | 机票乘客 |
| 机票 | ProjectFlightSegment | project_flight_segments | 机票航段 |
| 订单 | ProjectHeader | project_headers | 项目主表(HID) |
| 订单 | ProjectRef | project_refs | 业务明细(REF) |
| 会员订单 | Order | member_orders | 会员订单 |

### 当前问题
1. **产品表分散**：旅游产品、签证产品各自独立，无法统一管理
2. **缺少品类**：门票、用车、邮轮、酒店、保险等无独立产品表
3. **价格管理不统一**：各品类价格逻辑分散
4. **售卖规则缺失**：退改政策、预订规则无统一管理

---

## 二、升级目标架构

```
统一产品主表 (unified_products)
├─ 旅游线路扩展表 (product_tour_ext) - 复用现有 Product
├─ 签证扩展表 (product_visa_ext) - 整合 VisaTypes
├─ 门票扩展表 (product_ticket_ext) - 新增
├─ 用车扩展表 (product_car_ext) - 新增
├─ 邮轮扩展表 (product_cruise_ext) - 新增
├─ 酒店扩展表 (product_hotel_ext) - 新增
├─ 保险扩展表 (product_insurance_ext) - 新增
├─ 统一价格表 (unified_product_prices)
└─ 统一售卖规则表 (unified_sale_rules)
```

class UnifiedProduct(db.Model):
    """统一产品主表 - 所有产品共用核心字段"""
    __tablename__ = 'unified_products'

    id = db.Column(db.Integer, primary_key=True)
    product_code = db.Column(db.String(50), unique=True, nullable=False, comment='产品编号')
    product_name = db.Column(db.String(200), nullable=False, comment='产品名称')
    product_short_name = db.Column(db.String(100), comment='产品简称')

    # 分类
    product_category = db.Column(db.String(50), nullable=False, comment='产品大类：tour/visa/ticket/car/cruise/hotel/flight/insurance')
    product_sub_category = db.Column(db.String(50), comment='产品子类')

    # 销售信息
    sale_type = db.Column(db.String(20), default='service', comment='销售类型：实体/电子/服务')
    product_status = db.Column(db.String(20), default='draft', comment='状态：draft/active/inactive')
    is_hot = db.Column(db.Boolean, default=False, comment='是否主推')
    is_featured = db.Column(db.Boolean, default=False, comment='是否推荐')
    tags = db.Column(db.Text, comment='标签JSON')

    # 供应商
    supplier_id = db.Column(db.Integer, db.ForeignKey('suppliers.id'), comment='供应商ID')

    # 基础定价
    base_price = db.Column(db.Numeric(12, 2), comment='基础售价')
    cost_price = db.Column(db.Numeric(12, 2), comment='成本价')
    currency = db.Column(db.String(10), default='SGD', comment='币种')

    # 图片和描述
    cover_image = db.Column(db.String(500), comment='封面图')
    gallery_images = db.Column(db.Text, comment='图片库JSON')
    description = db.Column(db.Text, comment='产品描述')
    highlights = db.Column(db.Text, comment='产品亮点')

    # 有效期
    valid_from = db.Column(db.Date, comment='有效开始日期')
    valid_until = db.Column(db.Date, comment='有效结束日期')

    # 时间戳
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
    updated_at = db.Column(db.DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)
    created_by = db.Column(db.String(100), comment='创建人')

    # 扩展表ID（用于关联各品类扩展表）
    ext_table_id = db.Column(db.Integer, comment='扩展表记录ID')
```

# 迁移脚本：将 package_products 数据迁移到 unified_products
def migrate_tour_products():
    """迁移旅游产品到统一产品表"""
    from App_new.business.tour.models.Packagemodels import Product

    for old_product in Product.query.all():
        # 创建统一产品记录
        unified = UnifiedProduct(
            product_code=old_product.product_code,
            product_name=old_product.product_name,
            product_category='tour',
            product_sub_category=old_product.product_type,  # 跟团游/自由行/定制游
            supplier_id=old_product.supplier_id,
            base_price=old_product.base_price,
            currency=old_product.currency,
            cover_image=old_product.cover_image,
            gallery_images=old_product.gallery_images,
            description=old_product.product_description,
            highlights=old_product.highlights,
            product_status=old_product.product_status,
            valid_from=old_product.valid_from,
            valid_until=old_product.valid_until,
            ext_table_id=old_product.id  # 关联原旅游产品表
        )
        db.session.add(unified)

    db.session.commit()
```
