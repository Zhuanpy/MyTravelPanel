# 公司信息管理 - 快速入门指南

## 🎯 功能说明

通过后台统一管理公司信息（名称、Logo、联系方式等），前台和后台会自动同步显示，无需手动修改代码。

## 📍 访问入口

登录系统后，点击顶部导航：

```
业务管理 → 公司信息管理
```

或直接访问：`http://你的域名/company/edit`

## ⚡ 快速设置（3步完成）

### 第1步：填写基本信息

在公司信息管理页面填写：

- **公司名称** ✅ 必填，如：`悦行假期有限公司`
- **公司简介** ✅ 必填，如：`JOYFUL ESCAPES PTE LTD`
- **联系电话** ✅ 必填，如：`+65 9106 8716`
- **电子邮箱** ✅ 必填，如：`info@joyesc.com`
- **公司地址** ✅ 必填，如：`新加坡市中心商业区`

### 第2步：上传Logo

- 点击"公司Logo"下的文件选择按钮
- 选择Logo图片文件（支持JPG、PNG、GIF）
- 建议尺寸：200x200像素
- 会实时显示预览效果

### 第3步：保存

- 点击"保存更改"按钮
- 看到"公司信息更新成功！"提示即完成

## ✨ 自动生效的位置

保存后，以下位置会**自动更新**：

### 前台页面 (https://www.joyesc.com/public/)

1. **顶部导航栏**
   - Logo自动显示
   - 公司名称自动显示

2. **页面底部**
   - Logo自动显示
   - 公司名称自动显示
   - 联系信息自动显示（电话、邮箱、地址）

3. **联系我们页面**
   - 公司地址、电话、邮箱自动填充

### 后台系统

1. **公司抬头页面** - 用于打印文档
2. **报价单** - 自动显示公司信息
3. **公司抬头组件** - 可嵌入任何需要的地方

## 💡 使用技巧

### Logo推荐规格
- **格式：** PNG（支持透明背景）
- **尺寸：** 200x200 或 300x300 像素
- **文件大小：** 不超过2MB
- **背景：** 建议透明背景，适配深色和浅色背景

### 公司简介字段
- **公司名称：** 中文名称（如：悦行假期有限公司）
- **公司简介：** 英文名称或副标题（如：JOYFUL ESCAPES PTE LTD）

这样在显示时会形成：
```
悦行假期有限公司
JOYFUL ESCAPES PTE LTD
```

## 🔄 更新信息

需要更换Logo或修改信息时：

1. 重新进入"公司信息管理"页面
2. 修改需要更新的字段
3. 如需更换Logo，重新上传新文件
4. 点击"保存更改"
5. 刷新前台页面查看效果

## ❓ 常见问题

### Q: Logo不显示怎么办？
**A:** 
1. 检查文件是否成功上传
2. 刷新页面（Ctrl+F5）清除缓存
3. 检查Logo文件格式是否支持

### Q: 可以上传多个Logo吗？
**A:** 目前支持一个主Logo，会在所有位置统一使用

### Q: 修改信息后多久生效？
**A:** 立即生效，保存后刷新页面即可看到

### Q: 删除Logo怎么办？
**A:** 重新上传一个空白的或新的Logo即可替换

## 🎨 最佳实践

1. **Logo设计**
   - 简洁明了，避免复杂图案
   - 使用PNG透明背景
   - 确保在不同尺寸下都清晰可辨

2. **信息填写**
   - 使用官方正式名称
   - 联系方式保持最新
   - 地址写详细便于客户找到

3. **定期检查**
   - 每月检查一次信息是否准确
   - Logo是否需要更新
   - 联系方式是否有变化
