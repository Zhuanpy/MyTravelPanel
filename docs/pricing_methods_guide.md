# 配套价格预算 - 两套计价方式使用指南

## 概述

配套价格预算系统现在支持两种不同的计价方式，让您可以根据不同的业务场景选择最合适的计价模式。

## 计价方式对比

### 模板1：物品计价方式 🎁
**适用场景：** 按物品/服务数量计费，然后按人数分摊

**特点：**
- 输入物品单价和件数
- 系统自动计算物品总价
- 按适用人数分摊到大人和小孩
- 适合：酒店房间、包车服务、团体活动等

**计算公式：**
```
物品总价 = 物品单价 × 物品件数
人均分摊 = 物品总价 ÷ 适用人数
```

### 模板2：人均计价方式 👥
**适用场景：** 直接按人数计费

**特点：**
- 直接输入成人单价和儿童单价
- 系统自动计算总价
- 大人和小孩可以设置不同价格
- 适合：机票、门票、餐饮等

**计算公式：**
```
总价 = 成人单价 × 成人人数 + 儿童单价 × 儿童人数
```

## 使用步骤

### 1. 创建预算单
1. 进入"配套管理" → "价格预算"
2. 点击"新建预算单"
3. 填写基本信息（套餐名称、人数、币种等）
4. 保存预算单

### 2. 添加预算项目
1. 在预算单详情页面，点击"添加项目"
2. 填写项目基本信息（类别、类型、名称）
3. **选择计价方式：**
   - 点击"模板1：物品计价"或"模板2：人均计价"
   - 系统会显示对应的输入表单

### 3. 填写价格信息

#### 模板1：物品计价方式
```
物品单价：输入单个物品的价格
物品件数：输入需要的数量
适用人数：选择是否计算大人/小孩费用
```

#### 模板2：人均计价方式
```
成人单价：输入成人人均价格
儿童单价：输入儿童人均价格
适用人数：选择是否计算大人/小孩费用
```

### 4. 高级设置
- **人数覆盖：** 可以为特定项目设置不同的人数
- **总价覆盖：** 可以手动设置项目总价
- **税费设置：** 添加税率或税费金额
- **可选项目：** 标记为可选项目
- **备注信息：** 添加项目说明

## 实际应用示例

### 示例1：酒店住宿（模板1）
```
项目：豪华酒店房间
计价方式：物品计价
物品单价：$200/间
物品件数：1间
适用人数：大人2人，小孩1人

计算结果：
物品总价：$200
大人人均：$66.67
小孩人均：$66.67
项目小计：$200
```

### 示例2：机票费用（模板2）
```
项目：往返机票
计价方式：人均计价
成人单价：$150/人
儿童单价：$120/人
适用人数：大人2人，小孩1人

计算结果：
大人费用：$300 (2×$150)
小孩费用：$120 (1×$120)
项目小计：$420
```

### 示例3：餐饮服务（模板1，仅大人）
```
项目：特色餐厅
计价方式：物品计价
物品单价：$80/餐
物品件数：3餐
适用人数：仅大人2人

计算结果：
物品总价：$240
大人人均：$120 (仅大人分摊)
小孩人均：$0 (不计算)
项目小计：$240
```

## 界面功能

### 计价方式切换
- 在添加/编辑项目时，可以随时切换计价方式
- 切换时会自动清空不相关的字段
- 实时预览计算结果

### 自动计算
- 物品总价自动计算：单价 × 件数
- 人均价格自动计算：总价 ÷ 人数
- 项目小计自动更新

### 数据验证
- 必填字段验证
- 数值格式验证
- 计价方式一致性验证

## 最佳实践

### 选择合适的计价方式
1. **物品计价**：适用于按物品/服务数量收费的场景
2. **人均计价**：适用于按人数收费的场景

### 人数设置建议
1. **默认人数**：使用预算单设置的人数
2. **人数覆盖**：特殊情况下为项目设置不同人数
3. **适用选择**：灵活控制是否计算大人/小孩费用

### 价格管理
1. **总价覆盖**：当自动计算不符合实际时使用
2. **税费处理**：正确设置税率或税费金额
3. **可选项目**：标记客户可选择的服务

## 常见问题

### Q: 可以混合使用两种计价方式吗？
A: 可以！同一个预算单中的不同项目可以使用不同的计价方式。

### Q: 如何修改已创建项目的计价方式？
A: 点击项目的"编辑"按钮，在编辑页面可以切换计价方式。

### Q: 人数覆盖和总价覆盖有什么区别？
A: 人数覆盖是修改计算基数，总价覆盖是直接设置结果。

### Q: 可选项目会影响总价计算吗？
A: 可选项目会正常参与计算，但可以在报价时选择是否包含。
