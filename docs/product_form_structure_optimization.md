# 产品表单结构优化方案

## 📋 优化后的内容排序

### ✅ 推荐结构（按用户使用流程）

```
📄 产品编辑页面
│
├─ 📝 Form 区域（产品主表单）
│  │
│  ├─ 1️⃣ 基本信息 *必填多*
│  │   └─ 供应商、产品编号、产品名称、产品类型
│  │       国家、城市、出发/目的地、天数、人数
│  │
│  ├─ 2️⃣ 产品内容（核心卖点）
│  │   ├─ 产品描述
│  │   ├─ 产品亮点
│  │   ├─ 包含服务 / 不包含服务
│  │   └─ 重要提示
│  │
│  ├─ 3️⃣ 基础价格（默认价格）
│  │   └─ 成人/儿童/婴儿价格、单房差、货币
│  │
│  ├─ 4️⃣ 图片资源
│  │   ├─ 封面图
│  │   └─ 图片库
│  │
│  ├─ 5️⃣ 其他设置
│  │   ├─ 适合季节、难度等级
│  │   ├─ 产品状态、是否精选
│  │   ├─ 有效日期
│  │   └─ 联系人、标签
│  │
│  └─ 💾 保存按钮
│      └─ 保存产品 / 取消
│
├─ 🎯 高级功能区域（仅编辑模式显示）
│  │
│  ├─ 🗺️ 每日行程安排
│  │   └─ 行程列表 + 添加/编辑/删除
│  │
│  ├─ 💰 价格变体管理
│  │   └─ 变体列表 + 添加/编辑/删除
│  │
│  └─ 🔙 底部操作按钮
│      └─ 返回列表 / 修改基本信息
│
└─ 模态框（隐藏）
    ├─ 行程编辑模态框
    └─ 价格变体编辑模态框
```

---

## 🎯 优化理由

### 1️⃣ Form 内容按重要性排序

| 顺序 | 内容 | 理由 |
|------|------|------|
| 1 | 基本信息 | ✅ 产品身份，必填多，优先完成 |
| 2 | 产品内容 | ✅ 核心卖点，客户最关注 |
| 3 | 基础价格 | ✅ 快速定价，完成基础产品 |
| 4 | 图片资源 | ✅ 视觉展示，增强吸引力 |
| 5 | 其他设置 | ✅ 辅助信息，可后续补充 |

### 2️⃣ 高级功能独立于 Form

| 功能 | 位置 | 理由 |
|------|------|------|
| 行程管理 | Form 外部 | ✅ 需要产品先创建，逻辑独立 |
| 价格变体 | Form 外部 | ✅ 可选功能，避免干扰基本录入 |

### 3️⃣ 操作按钮分层

| 按钮 | 位置 | 用途 |
|------|------|------|
| 保存产品 | Form 底部 | ✅ 完成基本信息录入 |
| 返回列表 | 页面底部 | ✅ 完成所有操作后返回 |
| 修改基本信息 | 页面底部 | ✅ 快速跳转到顶部表单 |

## 🔄 逻辑流程

### 创建新产品
```
1. 填写基本信息（必填）
2. 填写产品内容
3. 设置基础价格
4. 上传图片
5. 完善其他信息
6. 点击"创建产品" ✅
   ↓
7. 自动跳转到编辑页面
8. 添加行程
9. 添加价格变体
10. 点击"返回列表" ✅
```

### 编辑现有产品
```
1. 查看/修改基本信息
2. 向下滚动，管理行程
3. 继续向下，管理价格变体
4. 点击底部"返回列表" ✅
   或
   点击"修改基本信息"跳回顶部 ✅
```
